================================================================================
背单词软件（vocabulary-pwa）— 界面功能与文件清单
================================================================================
项目类型：Vue 3 + TypeScript + Vite PWA（本地 IndexedDB）
路由方式：无 vue-router；由 App.vue 的 activeView 切换视图
文档范围：src 下 .vue / .ts 源文件 + 独立 CSS（不含 .vue.js 编译产物）
更新日期：2026-09-17

--------------------------------------------------------------------------------
一、应用视图总览（App.vue 可切换）
--------------------------------------------------------------------------------
study          → 学习主页 HomePage
profile        → 个人中心 ProfilePage
api            → API 设置
css-index      → 自定义外观入口
css-wallpaper  → 壁纸设置
css-font       → 字体设置
prompt-index   → 提示词配置入口
article-prompt → 文章生成提示词
quiz-prompt    → 选择题提示词
data-backup    → 数据备份
rss-feeds      → 新闻源 RSS
import         → 单词导入
vocabulary     → 单词本
article        → AI 主题短文生成会话
article-hub    → 阅读入口（AI / 今日新闻 / 已保存）
news-brief     → 今日新闻只读列表与段译
article-read   → 文章阅读页
word-quiz      → 默写/填空测验
choice-quiz    → AI 选择题练习

十二、业务服务（services）
================================================================================

src/services/article-generation.service.ts
  — 单例后台生成：按题材轮换（科技/教育等）分批写短文，AI 自选合适词直至用完；离页继续、落库、会话状态与订阅通知。

src/services/rss.service.ts
  — 预置/自定义 RSS 配置读写；开发态走 Vite 代理、生产走 allorigins 拉取并解析 RSS/Atom。

src/services/dictionary-api.service.ts
  — 查词：本地 ECDICT → 远程词典 API → 用户 LLM 补释义；导入时本地短语优先，缺失则 LLM 补固定搭配。

src/services/local-dictionary.service.ts
  — 首次从静态包导入离线词库、短语、形近与 Tatoeba 例句，并提供本地查词/短语/例句。

src/services/paragraph-revision.service.ts
  — 批量调用 LLM 润色已译段落并返回 JSON 修订。

src/services/speech.service.ts
  — Web Speech 音色列表、语速偏好与朗读/停止。

src/services/wallpaper.service.ts
  — 应用 CSS 壁纸变量、轮播定时与变更订阅。

src/services/font.service.ts
  — 注入 @font-face 并应用全局字体/颜色/字号。

src/services/data-backup.service.ts
  — 汇总/导出/解析/导入用户数据 JSON（排除可重建的大词库）。

src/services/practice-mix.service.ts

十五、补充说明
================================================================================

1. 路由模型
   无 vue-router；App.vue 的 View 联合类型覆盖全部页面与设置子页。

2. 未完成功能
   ArticleAnnotation.vue / useAnnotation.ts / types/annotation.ts
   均为批注功能骨架，尚未完整实现。

3. IndexedDB 结构
   - 主业务库：vocabulary-app（单词、文章、测验、配置等；含 localDict /
     localPhraseIndex / localLookalikeIndex / localExampleIndex，备份排除、可重建）
   - 壁纸库：由 wallpaper.repository 独立打开
   - 字体库：由 font.repository 独立打开

4. 离线词典静态包（public/dict）
   - ecdict-core.json：ECDICT 精简释义
   - ecdict-phrases.json：短语反查
   - ecdict-lookalikes.json：形近词
   - ecdict-examples.json：Tatoeba 例句（CC BY 2.0 FR；构建见 scripts/build-ecdict-examples.mjs）

4. 主要用户流程
   导入单词 → 单词本按日管理 → 生成/阅读新闻体短文（RSS 选题分批）
   → 默写测验 →（可选）进阶选择题 → 个人中心配置 API/外观/提示词/备份

6. 本文档后续可扩展
   「界面集成关系 / 页面跳转图 / 数据流」等章节可在此文件继续追加。
